# Social Media Addiction Prediction Using Machine Learning

## Mini Project

### Project Description

This project is a Machine Learning-based system for predicting the level of social media addiction based on social media usage and mental health-related factors.

The system predicts the user's addiction level as **Low, Moderate, or High** and provides suitable wellness recommendations.

### Machine Learning Model

* Random Forest Classifier
* Addiction Levels:

  * Low
  * Moderate
  * High

### Dataset

The project uses a dataset containing information related to social media usage, screen time, sleep, anxiety, and other relevant factors.

### How It Works

1. User provides the required information.
2. The input data is processed.
3. The trained Random Forest model predicts the addiction level.
4. The system displays the predicted level.
5. A suitable digital wellness recommendation is provided.
